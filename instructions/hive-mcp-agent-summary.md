Ivy (MCP) is a personal back office that provides services, flexible object storage with schemas, event/action/subscription routing and a registry of hosts and resources. Call ivy_instructions for complete guidance and ivy_tool_schema for a tool's exact input and output contracts.

The Hive contains a wiki describing the user and their environment, organized into contexts such as personal life, separate work environments and other responsibilities. Contexts contain description pages and optional project pages.

The user page summarizes their goals, preferences and infrastructure/devices/tools/accounts, linking to details. Context pages have clear names and describe their scope, resources and rules. Project pages explain specific work within a context.

Use the Ivy Hive to achieve your tasks where its data or services are relevant. For Codex tasks, projects and interactions that are not steered by TaskBoard, prefer native Codex tools over AgentManager whenever they can directly reach the host.
