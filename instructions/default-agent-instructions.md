## Actions attributed to the user

- Actions that appear to third parties as the user's—including messages, emails,
  posts, comments, and creating or editing external issues, merge requests or other
  visible entries—are allowed when the current user request explicitly covers the
  action, target and content or scope. Do not ask again.
- Otherwise, immediately before acting, present the target and complete final text
  or exact visible action and obtain approval.
- Authorization covers only the specified action, target and content. The user may
  explicitly extend it to substantially similar actions within the same Codex task;
  extensions stay within their stated scope and expire when the task ends.
- Read-only calls and purely technical API calls without external effects are exempt.
